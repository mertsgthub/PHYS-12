Week 6: Inputs

You have two assignments: create and calibrate a capacitive sensor and then use and calibrate another sensor.

Capacitive Sensor

In the class we made a sensor that calculates the water level by changing the permittivity. As we add water, which has higher permittivity than air increased our capacitence thus increasing the value we read in the serial monitor. Then, we took couple of readings for each level and created a table in order to create a graph. Lastly, we drew a best-fit curve to see the relation, and the result was as expected, a logarithmic curve like line appeared.

Ultrasonic Sensor

For the second sensor I selected an ultrasonic sensor to measure the distance and connected a buzzer. It buzzes louder as you get closer in a range of 0 <d <100cm. To calibrate it I changed the circuit and added a button instead of a buzzer so I can take discrete values when I press the button. Then, I created a system by laser cutter with known measurments to compare the real distance with the measured one. Also, I wrote two codes one helps to find the relation between time and distance and the other directly measures the difference so I can compare the real and measured distances.

The measured distance and the real distance turned out to be really close, so we can say that the sensor is overall precise. Also, when we plotted the time vs real distance graph we acquired a linear relationship, which we wanted. Since the formula of distance is d = v * t, we were expecting a linear relationship, where v is constant and its the speed of sound.
