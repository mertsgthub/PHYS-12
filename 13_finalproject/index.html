My Motivation:

This was a project that we tried to make in my aviation club as a drone project. We couldn't finished it, so I completely changed the design and did something much better and consistently working. This project's aim is to built a drone mounting that can dispense seed balls one by one to rural areas to green them.

Part 3: Coding

There is 4 different codes for my project: 3 written in Arduino IDE for the sender esp, receiver esp and esp-cam and 1 written in vs code for the local web server as a virtual remote controller and for the live feed. I connected all 3 esps by esp-now so they can interact with each other from long ranges. The remote sends the information to the stepper and servo's esp, and esp-cam sends the photos to the remote's esp, which is connected to my laptop, so I can run the local web server. ı developed all codes by the help of Claude

My Suggestions To Make It Better

If I would be recreating this I would first change the battery structure it is now running on 2 powerbanks and a wall ouput or the battery case. I will definitely use a single battery with two outputs for the esp32 and the esp-cam and a rechargble lithium battery with 12 volt output for the stepper. I will also create a housing for the cables. I will make the top part of it rectangular and than slowly transitioning it to the circular base for extra storage. Also, I will experiment with various attttachments for different usages.
